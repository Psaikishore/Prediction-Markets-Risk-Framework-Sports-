Predicting both teams' scores in NFL games with a multi-output random forest¶

This notebook reproduces every number in the results report. It runs end to end from the feature table built by scripts/build_features.py (run that first; it takes ~15 minutes from scratch, ~1 minute from the cached play-by-play aggregates).

Sections:

  1. Load the feature table and check what's in it
  2. Leakage check (single-game perturbation)
  3. Walk-forward evaluation: random forest vs ridge vs Elo vs closing line
  4. Point accuracy for home score, away score, margin and total
  5. The two-output structure: joint residuals and per-score calibration
  6. Feature importance
  7. Win probabilities from the two predicted scores
  8. Forecasts for the coming week

2. Leakage check¶

Every feature must be computable before kickoff. The test below takes one game, multiplies all its play-level statistics by 10 and adds 30 points to its score, rebuilds the team features and Elo, and checks that the game's own features are unchanged while later games of the two teams change. It perturbs one game at a time because an earlier perturbed game legitimately changes a later game's pre-game features through the opponents it played.

3. Walk-forward evaluation¶

Train on all seasons before t, test on season t, for t = 2010 … 2025. The targets are the two scores jointly (home_score, away_score); margin and total are derived from the two predictions. Market lines are excluded from the features. The closing line is kept only as a benchmark.

In [5]:
g = g[g.home_score.notna() & (g.season >= 2000)].reset_index(drop=True)
TARGETS = ["home_score", "away_score"]
EXCLUDE = {"home_score", "away_score", "margin", "total_pts", "home_win", "season", "week", "home_elo", "away_elo"}
MARKET = ["spread_line", "total_line", "home_moneyline", "away_moneyline", "home_spread_odds", "away_spread_odds",
          "over_odds", "under_odds", "market_p_home", "market_overround"]
FEATS = [c for c in g.columns if pd.api.types.is_numeric_dtype(g[c]) and c not in EXCLUDE and c not in MARKET]
assert not any(c in FEATS for c in ("result", "total", "overtime")), "post-game schedule fields must not be features"
print(len(FEATS), "features")

def rf():
    return make_pipeline(SimpleImputer(strategy="median", keep_empty_features=True),
                         RandomForestRegressor(n_estimators=500, min_samples_leaf=20, max_features=0.3, n_jobs=-1, random_state=0))
def ridge():
    return make_pipeline(SimpleImputer(strategy="median", keep_empty_features=True), StandardScaler(),
                         RidgeCV(alphas=np.logspace(0, 4, 15)))

TEST_SEASONS = list(range(2010, 2026))
preds, importances = [], []
t0 = time.time()
for t in TEST_SEASONS:
    tr, te = g[g.season < t], g[g.season == t]
    out = te[["game_id", "season", "week", "home_team", "away_team", "home_score", "away_score", "margin", "total_pts",
              "home_win", "spread_line", "total_line", "elo_spread", "elo_p_home", "market_p_home"]].copy()
    m = rf().fit(tr[FEATS], tr[TARGETS]); p = m.predict(te[FEATS])
    out["rf_home"], out["rf_away"] = p[:, 0], p[:, 1]
    importances.append(pd.Series(m[-1].feature_importances_, index=FEATS))
    r = ridge().fit(tr[FEATS], tr[TARGETS]); q = r.predict(te[FEATS])
    out["ridge_home"], out["ridge_away"] = q[:, 0], q[:, 1]
    out["avg_home"], out["avg_away"] = tr.home_score.mean(), tr.away_score.mean()
    preds.append(out); print(f"{t}: {len(te)} test games ({time.time()-t0:.0f}s)")
P = pd.concat(preds, ignore_index=True)
for mname in ["rf", "ridge", "avg"]:
    P[f"{mname}_margin"] = P[f"{mname}_home"] - P[f"{mname}_away"]
    P[f"{mname}_total"] = P[f"{mname}_home"] + P[f"{mname}_away"]
print(len(P), "out-of-sample predictions")

5. The two-output structure¶

The forest predicts a point in the (home score, away score) plane. The residuals around that point describe the uncertainty: their standard deviations and correlation are the (σ_h, σ_a, ρ) of a bivariate distribution. Calibration per score checks that predicted 20s are actually 20s on average.

In [8]:
P["res_h"], P["res_a"] = P.home_score - P.rf_home, P.away_score - P.rf_away

       "sd_home_score": P.home_score.std(), "sd_away_score": P.away_score.std(),

7. Win probability from the two predicted scores¶

Two ways to turn (predicted home, predicted away) into P(home wins): a bivariate normal with the residual covariance from section 5, and the empirical score grid tilted so that its mean margin and total match the forest's prediction (preserves key numbers such as 3 and 7). Both are compared with Elo and the de-vigged moneyline on 2016–2025.

In [11]:
from pmrisk.score_model import empirical_grid, tilt
sh, sa, rho = biv["sd_home_residual"], biv["sd_away_residual"], biv["corr_residuals"]
sd_margin = np.sqrt(sh**2 + sa**2 - 2 * rho * sh * sa)
P["p_win_bvn"] = stats.norm.cdf(P.rf_margin / sd_margin)
full = pd.read_parquet(DATA_PROCESSED / "features" / "games_features.parquet"); full = full[full.home_score.notna()]
P["p_win_grid"] = np.nan
for t in range(2016, 2026):
    prior = empirical_grid(full[full.season < t], smooth=0.02); idx = P.index[P.season == t]
    P.loc[idx, "p_win_grid"] = [tilt(prior, r.rf_margin, r.rf_total)[0].p_home_win() for r in P.loc[idx].itertuples()]
Q = P[P.season >= 2016]
def brier(p, y): m = p.notna() & y.notna(); return round(float(((p[m] - y[m]) ** 2).mean()), 4)
pd.Series({"forest -> bivariate normal": brier(Q.p_win_bvn, Q.home_win), "forest -> score grid": brier(Q.p_win_grid, Q.home_win),
           "Elo": brier(Q.elo_p_home, Q.home_win), "de-vigged moneyline": brier(Q.market_p_home, Q.home_win)}, name="win Brier 2016-2025").to_frame()
